## Adding a page

1. Create `src/ui_lvgl/page_x.cpp` following the pattern of the others: `page_x_creer(parent)` /
   `page_x_quitter()`, starting from any existing page.
2. Add it to the `pages[]` table in [src/ecran/ecran.cpp](../../src/ecran/ecran.cpp) (icon, title,
   functions) — the right-hand rail updates itself.
3. Define the contract first: add the section in [CONTRAT_MQTT.en.md](../../CONTRAT_MQTT.en.md)
   (`etat` / `set`), then the HA-side automation following the pattern of `ha_propositions/`.
4. Check in the simulator: add a state in `simu/donnees/` and a capture to the scenario
   (`simu/simu.cpp`), `make -C simu`.

## Diagnostics

- **Serial log**: `pio device monitor` (115,200 baud).
- **Remote log**: Telnet on screen port 23, without restarting —
  `python3 tools/banc.py journal 60`.
- **PC bench**: HTTP on port 8080, restricted to the `RESEAU_PC` machine — screen capture,
  simulated taps, traces, dump of the last crash (`tools/banc.py dump`).
- **Watchdog**: restarts a frozen loop; the restart reason and the previous crash
  are shown on the Info page.
- **Info page**: health (RAM/PSRAM, CPU temperature, git version), MQTT/Wi-Fi link green or
  red, event log.

## Simulator

```bash
make -C simu                 # compiles the ACTUAL page code, runs the scenario, writes simu/captures/*.png
make -C simu asan            # same pages under AddressSanitizer / UBSan
python3 simu/galerie.py galerie.html   # assembles the captures into a browsable HTML page
```

The simulator replays the MQTT messages from an anonymized real-world capture
([simu/donnees/](../../simu/donnees/)) and produces about 280 captures, including the images of the
three GIFs in the README. It is what built the README gallery — the code shown is
bit for bit the one on the screen (same sources, same `lv_conf.h`, 16-bit colors).
