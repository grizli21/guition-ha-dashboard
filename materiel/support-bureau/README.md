# Support de bureau — version « rotation 0 »

[English](README.en.md) | **Français**

Support imprimable pour l'écran Guition ESP32-S3-4848S040, adapté à l'orientation utilisée par
ce firmware (rotation 0 : voir [Sous le capot](../../docs/SOUS_LE_CAPOT.md)).

- Fichier : [`support_guition_rotation0.stl`](support_guition_rotation0.stl), 86,9 × 90,1 × 104,7 mm
  (sur GitHub, ouvrez-le : il s'affiche en 3D et se tourne à la souris).
- Modification par rapport au modèle de zervez : les crochets de fixation de l'écran sont tournés de 90°,
  pour tenir l'écran dans l'orientation de la rotation 0.
