# Desk stand — “rotation 0” version

**English** | [Français](README.md)

Printable stand for the Guition ESP32-S3-4848S040 display, adapted to the orientation used by
this firmware (rotation 0: see [Under the hood](../../docs/en/SOUS_LE_CAPOT.md)).

- File: [`support_guition_rotation0.stl`](support_guition_rotation0.stl), 86.9 × 90.1 × 104.7 mm
  (on GitHub, open it: it displays in 3D and turns with the mouse).
- Change compared with zervez's model: the display's mounting hooks are turned by 90°,
  to hold the display in the rotation 0 orientation.
